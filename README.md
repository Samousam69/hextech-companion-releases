# Hextech Companion

Compagnon League of Legends sans pub : builds OP.GG / u.gg importés automatiquement (runes, summoners, item set),
auto-accept, scouting au chargement, augments de l'ARAM du chaos, tier list, coach et fiches champions / items.

## Installer

1. Télécharge **`Hextech-Companion-Setup-….exe`** dans la [dernière version](https://github.com/Samousam69/hextech-companion-releases/releases/latest).
2. Lance-le. Windows SmartScreen peut afficher « Windows a protégé votre ordinateur » parce que l'installeur
   n'est pas signé : clique sur **Informations complémentaires**, puis **Exécuter quand même**.
3. L'appli s'installe et crée un raccourci sur le Bureau. Lance League of Legends, elle s'y connecte toute seule.

Les mises à jour sont automatiques : l'appli télécharge les nouvelles versions en arrière-plan et les installe
quand tu la fermes.

Ce dépôt ne contient que les versions publiées de l'appli.
